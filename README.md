# Project 01: Cleaning 1,000 Messy Sales Records Using Excel

This project was completed as a personal assignment during an Excel Bootcamp I participated in.

At the beginning of this learning journey, I had little to no experience using Microsoft Excel for data analysis. This assignment was one of my early opportunities to understand how Excel can be used to organize, clean, process, and analyze raw datasets.

The project involved working with a Superstore practice dataset containing 1,000 sales records. The main objective was to prepare the dataset and use Excel formulas to answer several business-related questions.

This project represents one of my first steps in developing practical data analysis skills.

## Learning Objectives

Through this assignment, I aimed to:

- Understand how to organize and prepare raw datasets.
- Learn how to clean incomplete and inconsistent data.
- Practice using Excel formulas and functions.
- Understand how to manipulate text and date values.
- Use lookup and conditional calculation functions.
- Extract useful information from a dataset to answer business questions.

## Tasks & Analysis Process

The assignment consisted of six main tasks:

**1. Data Organization**
- Organized columns and rows.
- Prepared the dataset for further analysis.

**2. Multi-Level Sorting**
- Sorted records by Order Date (ascending).
- Sorted Account Manager ID alphabetically (A–Z).
- Sorted Customer Name in descending alphabetical order (Z–A).

**3. Handling Missing Values**
- Identified blank cells and filled in the missing information as required by the assignment.

**4. Generating Order IDs**

Created a structured Order ID using four components:

- City initials.
- Customer name initials.
- Account Manager number.
- Order year.

Example: `JKT-WR-1028-2016`

Functions used:
- IFS
- LEFT
- MID
- FIND
- RIGHT
- Concatenation (&)

**5. Correcting Shipping Dates**
- Worked with inconsistent shipping date formats.
- Used DATE and text functions to reconstruct date values.
- Applied IFERROR to handle conversion errors.

**6. Answering Business Questions**

Used Excel formulas to answer five questions about shipping duration, product performance, and profitability.

Functions practised included:
- INDEX & MATCH
- SUMIFS
- AVERAGEIFS
- MAXIFS
- IFERROR

## Key Findings

Based on the completed assignment:

1. Product with the longest shipping duration: Smiths SlimLine Pencil Sharpener.
2. Most frequently ordered product: Cando PC940 Copier.
3. Product with the highest profit margin: Emerson LQ-870 Dot Matrix Printer.
4. Average Total Profit in 2018: approximately 7,623,843.03.
5. Total quantity of Wrap Bag sold in 2019: 2,104 units.

## Challenges & Learning Reflection

As someone who started learning Excel with very limited knowledge, this assignment introduced me to several functions and techniques that I had never used before.

One of the challenges was understanding how different Excel functions could work together to solve a single problem, particularly when generating Order IDs and correcting inconsistent date formats.

I also began to understand the importance of data preparation before performing any analysis.

One of my biggest takeaways from this assignment was that reliable analysis starts with reliable data. Even a well-written formula cannot produce trustworthy results if the underlying data is incomplete or incorrectly formatted.

This experience encouraged me to explore Excel beyond basic spreadsheet operations and motivated me to continue developing my data analytics skills.
